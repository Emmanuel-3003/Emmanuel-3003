## 🚀 Featured Projects

> Secure banking REST API for managing customers, accounts and money transfers.

- 10+ REST APIs across 3 modules (customers, accounts, transactions)
- **JWT authentication** with BCrypt-hashed passwords
- **Double-entry transfers**, deposits and withdrawals using `@Transactional` to keep balances consistent
- Account lifecycle states, centralized exception handling, pagination and sorting

`Java 21` `Spring Boot` `Spring Security` `JPA/Hibernate` `MySQL`

### 🛒 [E-Commerce API](https://github.com/Emmanuel-3003/E-Commerce)

- **JWT + role-based access control** for User, Seller and Admin

- Keyword search, pagination, image upload and **Swagger/OpenAPI** docs

`Java 17` `Spring Boot 3` `Spring Security` `JPA/Hibernate` `PostgreSQL`
